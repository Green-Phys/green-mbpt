# Citations and acknowledgments

Scientific work based on GREEN should acknowledge both the software and the
scientific methods on which the calculation relies.

Start from the canonical pages:

- <https://green-phys.org/docs/publications/>
- <https://green-phys.org/docs/acknowledgment/>
- <https://green-phys.org/data/iskakov2025.bib>

Use the software citation requested on the publications page. Also inspect the
relevant theory pages for the original literature behind the methods and
algorithms actually used, such as GF2, GW, self-energy embedding, convergence
acceleration, imaginary-time representations, or analytic continuation.

Do not infer that one software citation replaces method citations. Conversely,
do not produce an exhaustive bibliography of every transitive dependency.
Identify the calculation's actual methods and present the canonical references
to the researcher for final scholarly judgment.

Release-specific publications may supplement or supersede earlier guidance.
When the citation page and a release announcement differ, report the ambiguity
instead of silently choosing one.
